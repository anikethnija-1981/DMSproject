Core DMS Graph Terminology & Theory

Comprehensive Learning Hub

1. Graph G = (V, E)

Non-linear mathematical structure consisting of Vertices V and Edges E connecting pairs of vertices.

2. Vertex (Node)

Fundamental point in a graph representing an entity (e.g. computer, location, state).

3. Edge (Arc)

Connection line between two vertices representing a pathway or relationship.

4. Directed Graph (Digraph)

Graph where edges have fixed orientation (u → v).

5. Undirected Graph

Graph where edges are bidirectional, so (u, v) is identical to (v, u).

6. Visited Set / Array

Boolean tracking array that prevents infinite loops in cyclic graphs.

Time & Space Complexity Bounds

Time Complexity: O(V + E)

Every vertex is queued/pushed once O(V) and every edge is inspected during adjacency list traversal O(E).

Space Complexity: O(V)

Queue size (BFS) and call stack depth (DFS) require auxiliary memory proportional to total vertices O(V).

BFS vs DFS Algorithm Comparison

Feature Breadth-First Search (BFS) Depth-First Search (DFS)
Data Structure Queue (FIFO - First In First Out) Stack (LIFO - Last In First Out) / Recursion
Exploration Order Level-by-level (radiates outwards) Deep dive along a path until dead end, then backtracks
Shortest Path Guarantees shortest path in unweighted graphs Does NOT guarantee shortest path
Memory / Space Higher memory if graph is wide O(V) Lower memory if graph is narrow O(h)
Time Complexity O(V + E) O(V + E)

Breadth-First Search (BFS) Breakdown

Queue (FIFO) Level Order

BFS Algorithm Steps

  1. Select starting root vertex s.
  2. Mark s as discovered/visited.
  3. Enqueue s into the Queue.
  4. While Queue is not empty:
    • Dequeue vertex v from FRONT of Queue.
    • Add v to Traversal Order.
    • For each unvisited neighbor u of v:
      • Mark u visited.
      • Enqueue u to REAR of Queue.

Queue FIFO Structure

Neighbors discovered at Level k are processed before moving to Level k+1.

Depth-First Search (DFS) Breakdown

Stack (LIFO) / Backtracking

DFS Algorithm Steps

  1. Select starting root vertex s.
  2. Mark s visited and add to Traversal Order.
  3. Explore unvisited neighbor u deeper.
  4. Recursively repeat along the branch until no unvisited neighbors exist.
  5. Backtrack to previous ancestor when dead end is hit.
