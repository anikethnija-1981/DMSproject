1. Graph G = (V, E)

Non-linear mathematical structure consisting of Vertices V and Edges E connecting pairs of vertices.

2. Vertex (Node)

Fundamental point in a graph representing an entity (e.g. computer, location, state).

3. Edge (Arc)

Connection line between two vertices representing a pathway or relationship.

4. Directed Graph (Digraph)

Graph where edges have fixed orientation (u → v).

5. Undirected Graph

Graph where edges are bidirectional, so (u, v) is identical to (v, u).

6. Visited Set / Array

Boolean tracking array that prevents infinite loops in cyclic graphs.

Time & Space Complexity Bounds

Time Complexity: O(V + E)

Every vertex is queued/pushed once O(V) and every edge is inspected during adjacency list traversal O(E).

Space Complexity: O(V)

Queue size (BFS) and call stack depth (DFS) require auxiliary memory proportional to total vertices O(V).

BFS vs DFS Algorithm Comparison

Feature Breadth-First Search (BFS) Depth-First Search (DFS)
Data Structure Queue (FIFO - First In First Out) Stack (LIFO - Last In First Out) / Recursion
Exploration Order Level-by-level (radiates outwards) Deep dive along a path until dead end, then backtracks
Shortest Path Guarantees shortest path in unweighted graphs Does NOT guarantee shortest path
Memory / Space Higher memory if graph is wide O(V) Lower memory if graph is narrow O(h)
Time Complexity O(V + E) O(V + E)

Breadth-First Search (BFS) Breakdown

Queue (FIFO) Level Order

BFS Algorithm Steps

  1. Select starting root vertex s.
  2. Mark s as discovered/visited.
  3. Enqueue s into the Queue.
  4. While Queue is not empty:
    • Dequeue vertex v from FRONT of Queue.
    • Add v to Traversal Order.
    • For each unvisited neighbor u of v:
      • Mark u visited.
      • Enqueue u to REAR of Queue.

Queue FIFO Structure

Neighbors discovered at Level k are processed before moving to Level k+1.

📚 1. Graph Theory — Core Definitions

DMS Foundation

In Discrete Mathematical Structures (DMS), a graph is a fundamental non-linear data structure used to represent relationships between objects. Graphs underpin many real-world systems including social networks, routing algorithms, compiler design, and AI decision trees.

G

Graph G = (V, E)

A mathematical structure with a finite set of Vertices V (nodes) and a set of Edges E connecting pairs of vertices. Formally: G = (V, E) where E ⊆ V × V.

V

Vertex (Node)

A fundamental point/entity in the graph. Represented as a circle in diagrams. The set of all vertices is denoted V. Example: Cities in a map, users in a social network.

E

Edge (Arc)

A connection between two vertices. An edge (u, v) connects vertex u to vertex v. May be directed (one-way) or undirected (bidirectional).

→

Directed Graph (Digraph)

A graph where every edge has a specific direction. Edge (u → v) ≠ Edge (v → u). Used for one-way relationships like web links, task dependencies.

↔

Undirected Graph

A graph where edges are bidirectional. Edge {u, v} = Edge {v, u}. Models mutual relationships like friendships, roads between cities.

✓

Visited Set / Array

A boolean tracking structure that marks vertices as visited to prevent revisiting them. Critical for preventing infinite loops in cyclic graphs.

~

Adjacency List

A representation where each vertex stores a list of its neighboring vertices. Space: O(V + E). Most efficient for sparse graphs and traversal algorithms.

[]

Adjacency Matrix

A 2D matrix M[u][v] = 1 if edge exists, else 0. Space: O(V²). Best for dense graphs where fast edge lookups are needed.

∘

Path & Cycle

A path is a sequence of vertices where consecutive vertices are connected by edges. A cycle is a path where the first and last vertex are the same.

💡
Key Insight: Graphs model real-world networks. BFS and DFS are the two fundamental strategies to systematically visit every vertex in a graph exactly once, and they form the backbone of countless higher-level graph algorithms.

🌊 2. Breadth-First Search (BFS) — Theory

Queue · FIFO · Level Order

What is BFS?

BFS is a graph traversal algorithm that explores vertices level by level — starting from a source vertex and visiting all vertices at the current depth before moving on to the next depth level. It was first published by Konrad Zuse in 1945 and later popularized by Edward F. Moore in 1959 for finding shortest paths.

BFS uses a Queue (FIFO) data structure to keep track of vertices to visit next. The algorithm guarantees that when a vertex is first discovered, it is reached via the shortest possible path (minimum number of edges) from the source.

BFS Formal Algorithm

BFS(Graph G, start vertex s)
1.  Mark all vertices as UNVISITED
2.  Mark vertex s as VISITED
3.  Enqueue s into Queue Q
4.  WHILE Q is not empty:
5.      u ← Dequeue from FRONT of Q
6.      Output/Process u
7.      FOR each neighbor v of u in Adj[u]:
8.          IF v is UNVISITED:
9.              Mark v as VISITED
10.             Enqueue v to REAR of Q
11. END WHILE

BFS Key Properties

Data Structure Queue (FIFO — First In, First Out)
Traversal Order Level-by-level, radiating outward from source
Shortest Path ✅ Guarantees shortest path in unweighted graphs
Time Complexity O(V + E) — each vertex & edge processed once
Space Complexity O(V) — Queue stores at most all vertices
Completeness Complete — finds all reachable vertices

Real-World Applications

  • 🗺️ GPS Navigation — Shortest route in unweighted road networks
  • 👥 Social Networks — Degrees of separation (LinkedIn, Facebook)
  • 🌐 Web Crawling — Indexing pages level by level
  • 📡 P2P Networks — BitTorrent neighbor discovery
  • 🎮 Game AI — Finding nearest items/enemies in grid maps
🌊
Visual Analogy: Think of BFS like dropping a stone in water — ripples expand outward in concentric circles, visiting all vertices at distance 1, then distance 2, and so on. The Queue ensures we finish each "ring" before expanding further.

🌲 3. Depth-First Search (DFS) — Theory

Stack · LIFO · Backtracking

What is DFS?

DFS is a graph traversal algorithm that explores as deep as possible along each branch before backtracking. It picks one path and follows it to its end, then retreats to find unexplored branches. DFS was formally described by Charles Pierre Trémaux in the 19th century for solving mazes.

DFS uses a Stack (LIFO) data structure — either explicitly or via the program's call stack using recursion. DFS is the basis of many powerful algorithms including topological sort, strongly connected components (Tarjan's / Kosaraju's), and cycle detection.

DFS Formal Algorithm (Iterative)

DFS(Graph G, start vertex s) — Iterative
1.  Mark all vertices as UNVISITED
2.  Push s onto Stack S
3.  WHILE S is not empty:
4.      u ← Pop from TOP of S
5.      IF u is UNVISITED:
6.          Mark u as VISITED
7.          Output/Process u
8.          FOR each neighbor v of u in Adj[u]:
9.              IF v is UNVISITED:
10.                 Push v onto S
11. END WHILE

DFS Recursive Algorithm

DFS_Recursive(Graph G, vertex u, visited[])
1.  Mark u as VISITED
2.  Output/Process u
3.  FOR each neighbor v of u in Adj[u]:
4.      IF v is UNVISITED:
5.          DFS_Recursive(G, v, visited)
// Call DFS_Recursive(G, s, visited) to start

DFS Key Properties

Data Structure Stack (LIFO) or Recursion Call Stack
Traversal Order Deep-dive along one path, then backtrack
Shortest Path ❌ Does NOT guarantee shortest path
Time Complexity O(V + E) — same as BFS
Space Complexity O(h) where h = max depth of recursion tree
Backtracking ✅ Naturally supports backtracking

Real-World Applications

  • 📋 Topological Sort — Build systems, task scheduling (DAGs)
  • 🔍 Cycle Detection — Deadlock detection in OS scheduling
  • 🧩 Puzzles & Mazes — N-Queens, Sudoku, maze solving
  • 🌳 Spanning Trees — Finding DFS trees of a graph
  • 🤖 Game AI — Decision trees, game state exploration
🌲
Visual Analogy: Think of DFS like solving a maze — you go as far as possible in one direction. When you hit a dead end, you backtrack to the last junction and try a different path. The Stack (or recursion) remembers your path for backtracking.

⚖️ 5. BFS vs DFS — Comprehensive Comparison

Algorithm Analysis

Understanding when to use BFS versus DFS is a critical skill in algorithm design. Both have identical time complexity but differ significantly in memory usage, traversal behavior, and suitability for different problem types.

Feature / Property 🌊 BFS (Breadth-First Search) 🌲 DFS (Depth-First Search)
Data Structure Queue (FIFO) Stack (LIFO) / Recursion
Traversal Pattern Level-by-level (horizontal expansion) Deep dive along path (vertical, then backtrack)
Shortest Path ✅ Guaranteed (unweighted graphs) ❌ Not guaranteed
Time Complexity O(V + E) O(V + E)
Space Complexity O(V) — can be large for wide graphs O(h) — height of recursion tree
Memory Usage Higher for bushy/wide graphs Lower for narrow/deep graphs
Completeness Always finds solution if reachable May get trapped in deep/infinite paths
Cycle Handling Handles via visited set Handles via visited set
Best Use Cases Shortest path, level-order, web crawling Cycle detection, topological sort, mazes
Implementation Typically iterative (queue-based) Recursive or iterative (stack-based)
Output on Tree Level-order traversal Pre-order / Post-order / In-order
⚖️
When to Choose: Use BFS when you need the shortest path or level-order processing. Use DFS when memory is limited, you need backtracking, or you're working on topological ordering, cycle detection, or exhaustive path search.

🎯 6. Textbook-Style Activities

Guided Practice

These activities guide you step-by-step through the most important concepts tested in DMS graph traversal assignments. Complete them in order for the best learning outcome.

Activity 1 Tracing BFS on a Given Graph Beginner

Objective: Manually trace the BFS algorithm on a given undirected graph and record the traversal order and queue states.

Given Graph: V = {1, 2, 3, 4, 5, 6} with edges: (1,2), (1,3), (2,4), (2,5), (3,6)

Task:

  1. Draw the adjacency list for this graph.
  2. Apply BFS starting from vertex 1.
  3. Record the Queue state after each step.
  4. Write the BFS traversal order.
  5. Identify the BFS tree edges.
BFS Order: 1 → 2 → 3 → 4 → 5 → 6
Queue trace: [1] → [2,3] → [3,4,5] → [4,5,6] → [5,6] → [6] → []
Activity 2 Tracing DFS on the Same Graph Beginner

Objective: Apply DFS on the same graph from Activity 1 and compare the traversal with BFS.

Task:

  1. Apply DFS (recursive) starting from vertex 1 on the same graph.
  2. Record the call stack depth at each step.
  3. Write the DFS traversal order.
  4. Identify DFS tree edges and back edges.
  5. Compare with BFS result: which vertices were visited in different order?
DFS Order (recursive, alphabetical neighbors): 1 → 2 → 4 → 5 → 3 → 6
Comparison: BFS visits 3 before 4 and 5; DFS dives into 2's subtree (4, 5) before visiting 3.
Activity 3 Disconnected Graph Traversal Intermediate

Objective: Apply BFS and DFS to a disconnected graph and understand how to handle multiple components.

Given Graph: Component 1: Vertices {A, B, C} with edges (A,B), (B,C). Component 2: Vertices {D, E} with edge (D,E).

Task:

  1. Run BFS starting from A. Which vertices are visited?
  2. Run BFS starting from D. Which vertices are visited?
  3. Modify BFS to visit ALL vertices in a disconnected graph.
  4. How many connected components does this graph have?
BFS from A: Visits A, B, C only (Component 1).
BFS from D: Visits D, E only (Component 2).
Complete traversal: Run BFS/DFS from each unvisited vertex after each traversal completes.
Components: 2 connected components.
Activity 4 Cycle Detection Using DFS Intermediate

Objective: Use DFS to detect whether a graph contains a cycle.

Given Graph: V = {A, B, C, D} with edges (A,B), (B,C), (C,D), (D,B) — note edge D,B creates a cycle.

Task:

  1. Run DFS from vertex A.
  2. Track the recursion stack ("currently being processed" set).
  3. When does the algorithm detect a cycle?
  4. Which edge creates the back edge (cycle edge)?
Cycle Detected: When DFS visits D and finds neighbor B which is still in the recursion stack (currently being processed), a back edge (D→B) is found, indicating a cycle B→C→D→B.
